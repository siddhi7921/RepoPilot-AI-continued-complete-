Architecture

Transparent engineering workflow

Repository intelligence

Public GitHub commit and tree ingestion, source filtering, keyword retrieval, and commit-pinned context.

Investigation workflow

Structured stages for issue analysis, evidence retrieval, root-cause review, patch generation, and verification.

Execution isolation

Docker deployments use a separate restricted Python test runner; stronger per-job isolation is recommended for hostile public workloads.

Human review

Patch diffs, evidence, and test outcomes are surfaced for approval before any application or PR flow is offered.

Engineering principles

Evidence over unsupported claims

  • Tests before trust
  • Human approval before applying changes
  • Security-first execution boundaries
  • Transparent uncertainty and explicit limitations
